03 / Projects

Selected projects.

01

SHARP — Hybrid SPARQL Query Relaxation

Knowledge Graphs · Semantic Web · Ontology Reasoning · Embeddings

A hybrid framework for relaxing SPARQL queries when exact queries return no results. SHARP combines ontology-based reasoning with instance-level semantic similarity to generate and rank relevant relaxed queries.

The project introduces a ranking strategy and an evaluation benchmark incorporating human judgement to assess the relevance of relaxed answers.

Publication →
02

RELAXBench — Benchmark for SPARQL Query Relaxation

Knowledge Graphs · RDF-Star · SPARQL · Benchmarking · Evaluation

A benchmark designed to evaluate SPARQL query relaxation in knowledge graphs containing reified statements. RELAXBench extends LUBM4OBDA with RDF-Star data and queries specifically designed to test relaxation strategies.

The benchmark supports systematic evaluation of query rewriting, semantic similarity and ranking quality using metrics such as Precision, Recall, Jaccard, NDCG and RBO.

Project →
03

Research Paper Chatbot — RAG

LLMs · RAG · LangChain · Chroma · Embeddings · Python

An interactive question-answering system that allows users to upload and query research papers using Retrieval-Augmented Generation (RAG).

The application extracts and chunks documents, generates semantic embeddings, stores them in a vector database, and retrieves relevant passages before generating answers with a language model.

GitHub →
04

AI CV & Job Matching System

NLP · LLMs · Semantic Matching · Embeddings · Python

An AI-powered system designed to compare a candidate's CV with job descriptions and identify the most relevant opportunities.

The project uses NLP and semantic embeddings to extract skills, experience and requirements, calculate similarity between candidate profiles and job descriptions, and rank opportunities according to their relevance.
